# 변경 내역 — V2-CORE 설계 종합(개정 04)

## 무엇을 바꾸는가
`docs/specs/staking-yield-system-v2-prd-rev04-core-design-synthesis.md` 신규 작성.
A-2~A-10 설계 단계에서 각 에이전트가 상위로 escalate 한 항목을 `pm`이 판정하고,
V2-CORE 설계 단계의 종료 여부를 최종 판정한다.

## 왜 필요한가
1. **A-8 Q1 (HIGH)** — PoR-1′ 좌변이 스테이킹 원금을 이중 계상한다. A-3가 원금 락을
   소프트 락(잔고 불변)으로 확정했으므로 원금은 이미 로컬 원장 잔고 안에 있는데,
   rev02 §4.2의 좌변 문장이 그것을 별도 항으로 다시 더한다. 방치하면 불변식이 상시
   FAIL이 되고, 상시 FAIL은 운영자가 게이트를 끄게 만든다. **불변식의 소유자는 `pm`이다.**
2. **A-8 Q8 (HIGH)** — 레퍼럴·보상 플랜 부채가 좌변에 없어 준비금이 구조적으로
   과소 계상될 수 있다. 좌변 항목이 4개로 고정되어 있어 화면도 이 누락을 알 수 없다.
3. 그 외 A-2/A-5/A-6/A-7/A-9/A-10이 남긴 열린 항목의 "지금/이연/처리됨" 분류가 없으면
   마스터 보고에서 "설계 완료"의 의미가 불명확해진다.

## 범위
- 문서만 작성한다. **코드·스키마·마이그레이션 미변경.**
- rev01/02/03을 폐기하지 않는다. PoR-1′ 좌변 정의와 A-3 §2.6 / A-8 §5 데이터 계약만
  구속적으로 대체한다.
- A-3/A-4/A-8은 이 문서의 애드덤을 반영해야 마이그레이션 가능(문서 내 명시).
