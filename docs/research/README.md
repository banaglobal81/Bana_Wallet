# docs/research/

Cited external-research reports produced by the `researcher` agent (see `.claude/agents/researcher.md`).

- **Filename:** `<YYYY-MM-DD>-<topic-slug>.md`
- **Contents:** Summary · Findings (claim + confidence + source link) · Contradictions · Open Questions · Sources
- **Status:** findings only. These documents record what is *true externally*, not what BANA should do — product decisions live in `docs/specs/` and belong to `pm`.

For high-stakes questions needing adversarial multi-source verification, run the `/deep-research` skill from the main session instead; the agent cannot invoke it.
