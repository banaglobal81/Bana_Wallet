## 1. 스타일 결정 — 플랫 벡터 + 제한된 그레인

01 문서 §6.3이 이미 방향을 정했다(픽셀아트 금지, 플랫 벡터 채택). 이 문서는 그 실행 규칙을 못박는다.

- **참조 장르**: Hay Day / Township류 모바일 방치·경영 게임의 환경·캐릭터 아트. 레트로 게임 문법
  (픽셀·8비트)을 명시적으로 배제 — "실제 자금이 걸린 화면"이라는 톤 규칙(01 문서 §6.3) 때문.
- **선화**: 2~3px 두께의 어두운 윤곽선. 과도하게 굵은 만화체 아웃라인 금지.
- **셰이딩**: 셀셰이딩 1단(하이라이트 1 + 그림자 1). 리얼타임 그라디언트/PBR 금지.
- **그레인**: 저강도(약 4~6% 불투명도) 노이즈 텍스처를 전체에 얹어 완전히 밋밋한 벡터 느낌을 깬다.
- **금지**: 3D 렌더, 실사, 아니메(anime) 셀 스타일, 픽셀아트, 굵은 만화 잉크선.
- **문자**: 이미지에 어떤 텍스트·숫자·로고도 굽지 않는다(06 문서 M-1). 100% DOM 오버레이.

## 2. 캔버스·포맷 규칙 (승계)

- 내부 해상도 **960×540 고정**, `Scale.FIT`, `CENTER_BOTH` — 정수배 스케일을 보장하지 않으므로
  픽셀아트가 원천 배제된다(01 문서 §6.3의 실제 채택 근거 중 하나).
- 최종 포맷 **투명 PNG**(배경 레이어만 불투명 허용). WebP 변환은 배포 시점 선택.
- 배경 상·하단 각 12%는 저대비 유지 — DOM 오버레이 텍스트가 얹힐 자리(06 문서 M-6).

## 5. 배경 — 3레이어 패럴랙스

01 문서 §6.1 구조를 따른다: `sky`(고정/극저속) / `mid`(저속) / `fore`(리그와 동일 평면, 고정).
각 레이어는 챕터 팔레트(§3.2)를 반영하고, 사람·구조물 로고·읽을 수 있는 표지판을 넣지 않는다.
손실·사고·붕괴 묘사(W-1) 금지 — Ch2 "사층 돌파"도 **보강 작업 중**으로 그리지 **붕괴 사고**로
그리지 않는다.

## 6. 리그·시추정·프롭

- **리그 베이스(B2)만 Phase 0 대상.** 5개 장비 트랙(드릴/이수/냉각/동력/자동화) 부위 자체는
  그리지 않는다 — §0 참조. 리그 베이스는 챕터가 오를 때만 등급이 바뀌는(레벨 1/11/21/31/41/51)
  "몸체" 실루엣이다.
- **시추정(D1) 크기 등급은 약정일수(termDays) 기준.** 원금 크기를 암시하는 표현(더 큰 = 더 비싼
  포지션처럼 보이는 디테일, 예: 금색 도금·보석 장식)을 넣지 않는다 — 05 문서 AC-S12.
- 필드 프롭(D2)에는 표지 구조물이 있어도 문자를 넣지 않는다(M-1).

## 7. 알려진 파이프라인 한계 및 후속 작업

`make-image`(`pipeline/imagegen/generate.py`, Gemini `gemini-2.5-flash-image`) 사용 시 확인된
실제 제약. `docs/known-gaps.md` 근거.

| 제약 | 대응 |
|---|---|
| **진짜 알파 투명 PNG를 직접 생성하지 못한다** — 결과물이 항상 불투명 배경으로 나온다 | 스프라이트류는 프롬프트에 "flat solid magenta (#FF00FF) background, chroma-key" 지시를 넣어 생성한 뒤, 별도 파이썬(PIL) 스크립트로 마젠타를 알파로 치환해 투명 PNG로 후처리했다. 매팅 품질은 자동 임계값 기반이라 복잡한 실루엣 가장자리(머리카락 등)는 완벽하지 않을 수 있음 — 프로덕션 마무리 시 수동 정리 권장 |
| **여러 이미지 간 캐릭터 일관성 보장 메커니즘 없음**(참조 이미지 1장만 지원, 캐릭터 시트 배치 기능 없음) | §4의 확정 외형 서술을 매 생성 프롬프트에 그대로 재사용해 최대한 근접시켰다. 완전한 동일 캐릭터 보장은 안 됨 — 향후 `--reference-image`로 확정 포즈를 고정 참조로 사용하는 2차 패스를 권장 |
| **패럴랙스 레이어의 정확한 매니페스트 규격(1920×540 sky/mid, 960×200 fore)을 파이프라인이 직접 지원하지 않음**(종횡비만 검증, 초광각 비율 미지원 가능성) | 이번 배치는 전부 **16:9(≈960×540)** 로 생성했다. 좌우로 스크롤되는 광폭 캔버스가 필요하면 후속 아웃페인팅/타일링 작업이 필요 — `game-developer`가 필요 시 재요청 |
| **시드 고정·부분 재생성 없음** — 프롬프트를 살짝 바꿔도 전체가 새로 생성됨 | 특정 프레임만 미세 수정하려면 재생성 후 육안 비교로 채택/폐기 판단 |
| **Vertex AI 공유 쿼터 2 req/분** | 배치 스크립트가 호출 간 38초 간격을 둠 — 대량 생성 시 시간이 오래 걸림(이번 배치 33장 ≈ 25~30분) |

## 8. 톤/금지 재확인 (01 문서 §2.5, 06 문서 M-7~M-9)

모든 프롬프트에 아래를 하드 네거티브로 포함했다: 손실/사고/부상/파손 묘사 없음, 도박·뽑기·
보물상자 모티프 없음, 실존 브랜드·국기·인물 없음, 이미지 내 텍스트/숫자/로고 없음, 승전보·폭죽·
과장된 축하 이펙트 없음(인양 버스트는 "차분한 방사형 글로우"로 한정, 05 문서 §3.3의 "1회 버스트 +
1.2초 카운트업, 화면 흔들림·폭죽 금지" 규칙 반영).
